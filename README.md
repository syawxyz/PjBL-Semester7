# PjBL-Semester7_ week1

# HASIL Disuksi Proyek dengan PT Integrasi Bisnis Eksekutif

Terdapat forklift elektrik (pallet stacker) yang telah dikerjakan pada semester sebelumnya, forklift dilengkapi dengan STM32, komunikasi CAN bus, LiDAR 2D, IMU, dan encoder motor. Forklift saat ini dapat dikendalikan menggunakan remote nirkabel, tetapi belum mampu beroperasi secara otonom. Fork hidrolik hanya dapat dinaikkan dan diturunkan secara manual: belum ada sensor ketinggian fork, sehingga tinggi fork tidak terukur dan tidak dapat dikendalikan ke posisi tertentu. Kondisi tersebut membatasi penerapan forklift untuk proses material handling yang membutuhkan perpindahan otomatis antar area dan pengaturan tinggi fork sesuai tingkat rak, sehingga diperlukan pengembangan sistem navigasi otonom berbasis ROS 2 serta instrumentasi dan kendali ketinggian fork.
